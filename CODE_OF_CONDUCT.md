# Code of Conduct

This project follows a professional, respectful, and research-oriented collaboration standard.

Participants are expected to:

- Communicate respectfully.
- Keep technical critique evidence-based.
- Preserve patent-safe disclosure boundaries.
- Avoid sharing confidential implementation details.
- Attribute public technical sources.
- Keep benchmark claims accurate and reproducible.

Unacceptable behavior includes harassment, disclosure of private information, publication of proprietary internals, or intentionally misleading benchmark claims.
