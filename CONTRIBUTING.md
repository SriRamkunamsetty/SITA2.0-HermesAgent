# Contributing

Thank you for contributing to the SITA Hermes Agent AMD AI infrastructure package.

## Scope

This repository accepts contributions related to:

- AMD ROCm setup documentation
- AMD GPU benchmark methodology
- Public reproducibility workflows
- Patent-safe diagrams
- Enterprise deployment notes
- Benchmark table improvements
- References to public AMD documentation

## Patent Safety

Do not contribute:

- Proprietary orchestration logic
- Confidential architecture components
- Internal optimization modules
- Secret agent workflows
- Patent-sensitive implementation details
- Private datasets or sensitive video captures

Use high-level language such as:

- proprietary orchestration layer
- confidential architecture components omitted
- internal optimization modules
- custom optimized workflow

## Pull Request Checklist

- The change is public-safe.
- AMD/ROCm claims are sourced from official documentation where possible.
- Benchmark values are clearly labeled as measured or template values.
- No secrets, private logs, or proprietary traces are included.
- Markdown tables render cleanly.
